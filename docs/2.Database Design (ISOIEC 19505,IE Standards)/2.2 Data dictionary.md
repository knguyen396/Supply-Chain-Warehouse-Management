# DATA DICTIONARY

## 1. Warehouse

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| warehouse_id | VARCHAR(10) | PK | Unique identifier of the warehouse |
| warehouse_name | VARCHAR(100) | NOT NULL | Name of the warehouse |
| location_address | TEXT | NOT NULL | Physical address of the warehouse |
| capacity | INT | NOT NULL, CHECK (capacity > 0) | Maximum storage capacity of the warehouse |

## 2. Product

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| product_id | VARCHAR(10) | PK | Unique identifier of the product |
| product_name | VARCHAR(100) | NOT NULL | Name of the product |
| unit | VARCHAR(20) | NOT NULL | Unit of measurement |
| min_reorder_level | INT | NOT NULL, DEFAULT 0, CHECK (min_reorder_level >= 0) | Minimum stock level that triggers replenishment |
| unit_price | DECIMAL(10,2) | NOT NULL, CHECK (unit_price >= 0) | Price per unit of the product |

## 3. Supplier

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| supplier_id | VARCHAR(10) | PK | Unique identifier of the supplier |
| supplier_name | VARCHAR(100) | NOT NULL | Name of the supplier |
| contact_email | VARCHAR(100) | NULL | Supplier's contact email |
| phone_number | VARCHAR(20) | NULL | Supplier's phone number |
| address | TEXT | NULL | Supplier's address |

## 4. SupplierOrder

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| order_id | VARCHAR(10) | PK | Unique identifier of the supplier order |
| supplier_id | VARCHAR(10) | FK, NOT NULL | Identifier of the supplier associated with the order |
| order_date | DATE | NOT NULL | Date when the order was created |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'Pending', CHECK (status IN ('Pending', 'Completed', 'Canceled')) | Current status of the supplier order |
| total_amount | DECIMAL(12,2) | NOT NULL, DEFAULT 0, CHECK (total_amount >= 0) | Total value of the supplier order |

## 5. Shipment

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| shipment_id | VARCHAR(10) | PK | Unique identifier of the shipment |
| tracking_number | VARCHAR(50) | NOT NULL, UNIQUE | Unique shipment tracking number |
| source_warehouse_id | VARCHAR(10) | FK, NOT NULL | Warehouse from which the shipment is sent |
| dest_warehouse_id | VARCHAR(10) | FK, NOT NULL | Warehouse receiving the shipment |
| dispatch_date | DATETIME | NOT NULL | Date and time when the shipment is dispatched |
| estimated_arrival | DATETIME | NOT NULL | Expected arrival date and time |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'Pending', CHECK (status IN ('Pending', 'In-Transit', 'Completed', 'Canceled')) | Current status of the shipment |

**Additional constraints:**
- `CHECK (source_warehouse_id <> dest_warehouse_id)`: Source and destination warehouses must be different.
- `CHECK (estimated_arrival >= dispatch_date)`: Estimated arrival must not be earlier than dispatch time.

## 6. Inventory

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| warehouse_id | VARCHAR(10) | PK, FK, NOT NULL | Identifier of the warehouse storing the product |
| product_id | VARCHAR(10) | PK, FK, NOT NULL | Identifier of the stored product |
| quantity_on_hand | INT | NOT NULL, DEFAULT 0, CHECK (quantity_on_hand >= 0) | Current quantity of the product in the warehouse |
| last_updated | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | Date and time when inventory information was last updated |

**Primary Key:** `(warehouse_id, product_id)`

## 7. ProductStructure

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| parent_product_id | VARCHAR(10) | PK, FK, NOT NULL | Identifier of the parent product |
| child_component_id | VARCHAR(10) | PK, FK, NOT NULL | Identifier of the component product |
| quantity_required | INT | NOT NULL, CHECK (quantity_required > 0) | Quantity of the component required to produce the parent product |

**Additional constraint:**
- `CHECK (parent_product_id <> child_component_id)`: A product cannot be its own component.

**Primary Key:** `(parent_product_id, child_component_id)`

## 8. SupplierOrderDetail

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| order_id | VARCHAR(10) | PK, FK, NOT NULL | Identifier of the supplier order |
| product_id | VARCHAR(10) | PK, FK, NOT NULL | Identifier of the ordered product |
| order_quantity | INT | NOT NULL, CHECK (order_quantity > 0) | Quantity of the product ordered |
| unit_price | DECIMAL(10,2) | NOT NULL, CHECK (unit_price >= 0) | Price per unit at the time of ordering |

**Primary Key:** `(order_id, product_id)`

## 9. ShipmentDetail

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| shipment_id | VARCHAR(10) | PK, FK, NOT NULL | Identifier of the shipment |
| product_id | VARCHAR(10) | PK, FK, NOT NULL | Identifier of the shipped product |
| shipped_quantity | INT | NOT NULL, CHECK (shipped_quantity > 0) | Quantity of the product included in the shipment |

**Primary Key:** `(shipment_id, product_id)`

## 10. RestockAlert

| Attribute | Data Type | Constraints | Description |
|---|---|---|---|
| alert_id | VARCHAR(10) | PK | Unique identifier of the restock alert |
| warehouse_id | VARCHAR(10) | FK, NOT NULL | Identifier of the warehouse where the alert is generated |
| product_id | VARCHAR(10) | FK, NOT NULL | Identifier of the product requiring attention |
| alert_date | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | Date and time when the alert was created |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'Pending', CHECK (status IN ('Pending', 'Resolved')) | Current status of the restock alert |

**Foreign Key:** `(warehouse_id, product_id)` references `Inventory(warehouse_id, product_id)`.
