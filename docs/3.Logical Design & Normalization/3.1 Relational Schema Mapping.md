-The conceptual EER/UML model is mapped into ten relational tables. Primary keys identify records uniquely, while foreign keys represent relationships between tables. Composite primary keys are used for associative entities where appropriate.

-WAREHOUSE(warehouse_id, warehouse_name, location_address, capacity) 

-PRODUCT (product_id, product_name, unit, min_reorder_level, unit_price) 

-SUPPLIER (supplier_id, supplier_name, contact_email, phone_number, address)

-SUPPLIER_ORDER (order_id, supplier_id (FK), order_date, status, total_amount) 

-SHIPMENT (shipment_id, tracking_number, source_warehouse_id (FK), dest_warehouse_id (FK), dispatch_date, estimated_arrival, status) 

-INVENTORY (warehouse_id (PK, FK), product_id (PK, FK), quantity_on_hand, last_updated) 

-PRODUCT_STRUCTURE (parent_product_id (PK, FK), child_component_id (PK, FK), quantity_required) 

-SUPPLIER_ORDER_DETAIL (order_id (PK, FK), product_id (PK, FK), order_quantity, unit_price) 

-SHIPMENT_DETAIL (shipment_id (PK, FK), product_id (PK, FK), shipped_quantity) 

-RESTOCK_ALERT (alert_id, warehouse_id (FK), product_id (FK), alert_date, status)
